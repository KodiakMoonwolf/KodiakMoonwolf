## 📦 Featured project: [PowerShell](https://github.com/KodiakMoonwolf/PowerShell)

My main scripting repo: a collection of functions and scripts for sysadmins and PowerShell users.

| Tool | What it does |
| --- | --- |
| `Get-DNSData` | A, MX, NS, CAA, CNAME and AAAA lookups via Google DNS over HTTPS, with pipeline input and CSV export |
| `Get-DomainRegInfo` | Checks whether a domain is registered and returns RDAP info |
| `Get-MacVendors` | MAC address vendor lookup |
| `Get/Set-1passwordsecret` | Read and write 1Password item fields using the `op` CLI |
| `trains/` | UK rail helpers built on the Realtime Trains API |
| `Sandbox/` | Exchange Online, Entra/Graph, SSL and LastPass tooling |

Everything is MIT licensed and most functions ship with comment-based help, so `Get-Help <name> -Full` works.
